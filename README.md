# BPharmHub – AKTU B.Pharm Notes, PYQs & Study Tools

Your one-stop study hub for AKTU B.Pharm students (Sem 1–8).  
Free notes, solved PYQs, important questions, GPAT tools & more.

🌐 Live: [bpharmhub.xyz](https://bpharmhub.xyz)

---

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

2. Copy `.env.example` to `.env` and fill in your keys:
   ```bash
   cp .env.example .env
   ```

3. Run the app:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
